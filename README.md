# Maven Market — End-to-End Retail & Returns Analytics Dashboard

## 📌 Project Overview
This project delivers a comprehensive, multi-perspective Business Intelligence solution for **Maven Market**, a multi-national retail chain. Using **SQL Server**, **DAX**, and **Power BI**, the project analyzes customer behavior, sales trends, product profitability, and operational return dynamics across 7 distinct analytic domains to minimize revenue risk and optimize retail performance.

## 📊 Dashboard Modules & Key Sections

The final dashboard is structured into 7 core analytical modules:

1. **Executive Overview:** High-level KPIs, total revenue, profit metrics, and geographic performance.
2. **Sales & Revenue Analysis:** Granular examination of revenue drivers, order volumes, and regional trends.
3. **Product & Brand Performance:** Category analysis, product margin evaluation, and top/bottom performers.
4. **Customer Behavioral Intelligence:** Demographics, income segmentation, and purchase frequency distributions.
5. **Store Operations Analytics:** Store-level revenue efficiency, sales density, and location metrics.
6. **Financial & Margin Deep-Dive:** Profitability ratios, cost analysis, and basket size tracking.
7. **Returns Analysis & Operational Impact:** Operational losses, returned unit volumes, return rates, and financial risks.

## 🛠️ Tech Stack & Tools

* **Database & Querying:** Microsoft SQL Server / T-SQL
* **Business Intelligence & Visualization:** Power BI Desktop
* **Data Modeling & Calculations:** DAX (Data Analysis Expressions)
* **Data Preparation:** Power Query (ETL pipeline)

## ⚙️ Requirements & Prerequisites

To open and run this project, ensure you have the following installed:

* **Power BI Desktop** (Version: 2023 or later recommended)
* **SQL Server Management Studio (SSMS)** or **SQL Server** (to run standalone T-SQL scripts)
* Maven Market source datasets (`MavenMarket_Customers.csv`, `MavenMarket_Products.csv`, `MavenMarket_Stores.csv`, `MavenMarket_Returns.csv`, `MavenMarket_Transactions_All.csv`, `MavenMarket_Calendar.csv`)
